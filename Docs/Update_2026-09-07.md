# 能量制技能与云端立交更新

## 已实现

- 技能无冷却。满能量即可释放，包括技能仍在生效时；重新释放刷新时长，不叠加速度或无限累积时长。
- 技能自然回复由每秒 5.5% 调为 3.5%，技能电池仍回复 34%。氮气按 34% 消耗，也不再用生效计时阻挡手动释放。
- 重盾每次成功挡撞回收 12% 技能能量及 12% 氮气，每次开盾最多触发三次；取消撞击延长护盾。
- 脉冲提速 28%、持续 3.5 秒；命中每个有效目标回收 8% 技能能量，单次释放最多 24%。
- 基础速度恢复为 47，玩家与 NPC 使用相同速度公式。保留 0.13 秒相邻变道和单槽输入缓冲。
- 玩家第 3 道起跑，另外五个球占据其余五道，同一纵向起跑位置。NPC 的角色替换仍按开局随机，不随机改地图。
- 选角色 → 选地图 → 三秒倒计时。保留星环观测站，新增云端立交，分别保存记录。

## 云端立交

固定路线，无跑图中生成网格。主道约 2200 米，三圈。

| 分流 | 入口范围（从左起） | 桥面宽度 | 支线相对高度 | 对应主道 / 支线路程 |
| --- | --- | --- | --- | --- |
| 1 | 第 1–2 道 | 2 道 | +22 米 | 410.3 / 359.8 米 |
| 2 | 第 4–6 道 | 3 道 | -12 米 | 443.8 / 408.8 米 |
| 3 | 第 1–4 道 | 4 道 | +28 米 | 446.4 / 398.5 米 |
| 4 | 第 3–6 道 | 4 道 | +18 米 | 449.2 / 411.1 米 |

高度相对未加绕行起伏的基础主线，非全程恒定的路面净空。入口以橙色箭头和立柱提示；不在入口车道的球沿主道行驶。支线汇入六道道路，最后强制返回主道；不能永远留在内线刷圈。

桥上允许在实际宽度内相邻变道，支持拾取、炸弹、氮气带及角色技能判定。路径 ID 隔离上下层道具，不能隔着楼层吸取或引爆。

共 200 个补给、142 个赛道设施（包括加速带），采用固定遭遇节奏而非随机撒点。主道也有炸弹；障碍至少留出通行车道。远景增加轨道行星、浮空站、楼群及桥墩。

## 性能与边界

- 新图比赛逻辑 60 FPS 步进平均约 0.29–0.31 ms，P95 约 0.45–0.48 ms；该模拟区间测得托管分配 0 字节。
- 1115×627 编辑器 Game View 抽样约 143 Draw Calls、4.38 万三角形。仅一个视点，不是全图峰值或手机 GPU 基准。
- 道路分区按材质合并、远景按材质合并，保留道具可见性裁剪。地图切换释放生成的网格，不销毁共享基础网格。
- 未进行 Android 真机帧率、发热、音频延迟测量；不能将编辑器逻辑耗时视为手机整帧耗时。
- 地图与规则不同会影响成绩及角色路线选择；角色平衡仍需真人实玩反馈，不以自动驾驶用时宣称最终平衡。

## 调整入口

- `CircuitCatalog.cs`：地图名、独立记录键、固定锚点、分流位置/宽度/层高。
- `AuthoredCircuit.cs`：弧长缓存、主道绕行、桥面网格、车道映射、远景。
- `SkyCourse.cs`：新图遭遇编排、地图选择 UI。
- `RaceBalance.cs`：自然回复、消耗、持续时长、速度增益与角色说明。
- `RacerController.cs`：变道、能量释放、护盾回收。
- `TrackItems.cs`：主道/支线隔离判定、逐球逐圈恢复。
- `Resources/RaceAudio.asset`：此前修复的两段 BGM 已保留；选角音量 0.16，比赛音量 0.70，确认出战后延迟 0.5 秒播放比赛音乐。
