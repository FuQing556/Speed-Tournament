# 起步喷射与音频调整

## 起步

- GO 前 0.35 秒至 GO 后 0.20 秒，按氮气（手机按下触发，电脑空格）。
- 提前命中显示“已就绪”，到 GO 发动；GO 后命中立即发动。
- 免费、每局一次、速度 +35%、持续 1.2 秒，不消耗氮气或角色能量。基础 47 m/s → 63.45 m/s。
- 过早点击不惩罚、不预存起步；窗口内连点不重复喷射、不扣氮气。窗口结束后按原规则释放普通氮气，未新增技能冷却。
- 起步可与技能/氮气叠加，但仍受总增益 +68% 的原上限约束。
- 增加 GO 显示、按键提示与青色/白色喷射尾焰；尾焰每球两个 16 三角面网格，复用、不动态创建粒子或灯光。
- 驾驶手册已同步，显示数值引用 RaceBalance 常量。

## 输入

手机技能和氮气改为 PointerDown，不等松手。Button.onClick 不再重复触发动作；UI Submit 保留。键盘的空格/Ctrl 移到每渲染帧采集一次，避免低帧率下多个模拟子步把一次按键当作多次释放。

## 音频

- 保留现有 BGM 引用、菜单音量 0.16、比赛音量 0.7 和比赛音乐延迟 0.5 秒。
- 原效果声被合成幅度、AudioSource 音量、OneShot 增益多层削弱。本次统一合成峰值与分类增益；效果总音量 0.28 → 0.78。
- 起步为 0.90 秒喷射声、普通氮气为 0.70 秒，加速带使用更短的 0.30 秒提示。
- 疾风：上扬推进；重盾：金属共振；脉冲：三段冲击；引力：周期调制；幻影：下降掠过；蓄能：上行阶梯电音。
- 倒计时、喷射、技能和结算期间短暂压低 BGM 至常态的 28%，随后平滑恢复。这里不修改音乐文件或常态音量。
- 1 路音乐 + 3 路有界音效声部（细节、喷射、技能）；拾取和切轨不会挤掉技能音效，不叠加无限 OneShot 尾音。
- 合成音频仅在初始化创建并缓存；播放期间不合成或分配采样数组。暂停会冻结音频与压低状态，退出销毁运行时音频。
- 可调项在 Assets/SpeedTournament/Resources/RaceAudio.asset：effectsVolume、criticalMusicFactor、musicRecoverySeconds。后者为指数恢复时间常数，非硬切换。

## 验证

- LaunchAudioValidation.Run：188 组 PASS。六角色、20/30/60 FPS、提前/临界/错过/无输入、免费与防重复、暂停、速度上限、实际 uGUI PointerDown、音频峰值、六音色差异、BGM 压低与恢复。
- 所有生成声音峰值 0.720，无空音频/NaN；这属于采样与播放逻辑验证，不等同于手机扬声器主观试听或硬件延迟测量。
- 两图疾风无起步输入的完整比赛回归仍为 80.82 / 95.06 秒，贴轨、连续性和资源检查通过，没有改变既有竞速平衡。
- 最终 Unity 控制台无游戏错误或警告。测试使用 ManualSimulation，不保存玩家最好成绩。

主要实现：RaceLaunch.cs、RaceSound.cs、RaceBalance.cs；验证：Editor/LaunchAudioValidation.cs。
